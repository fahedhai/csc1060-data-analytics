# 📊 CSC1060 — Data Analytics Fundamentals

**Author:** Fahed Haidar — IT/Data Science Student

This repository contains two data analytics projects completed as part of CSC1060 Data Analytics Fundamentals.

The projects demonstrate the full data analytics workflow, including:

- Data cleaning and preparation
- Exploratory data analysis
- Data visualisation
- Statistical analysis
- Regression modelling
- Machine learning
- Model evaluation
- Interpretation of results

### Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Git & GitHub

## Assessment 1: [Arthritis Prevalence Among Older Adults](assessment-1-arthritis/)
Exploratory analysis of CDC health data examining arthritis prevalence among older adults across geographic locations, sex, race/ethnicity, and year.

The analysis includes data cleaning, descriptive statistics, data visualisation, and statistical analysis to identify patterns and differences in arthritis prevalence. A linear regression model was also used to investigate whether year alone could explain changes in prevalence over time.

## Assessment 2: [Predicting Student Final Grades](assessment-2-student-performance/)

A predictive data analysis project using student performance data to investigate which factors are associated with final academic grades.

The project includes data preparation, exploratory analysis, feature selection, and comparison of three regression models: Linear Regression, Decision Tree, and Random Forest.

Linear Regression achieved the strongest performance, with an R² score of 0.88, demonstrating a strong relationship between the selected features and students' final grades.
