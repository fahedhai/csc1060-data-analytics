# CSC1060 - Data Analytics Fundamentals

Two coursework assessments applying the full data analytics lifecycle
(data preparation, exploratory analysis, modeling, evaluation) to
real-world datasets using Python (pandas, matplotlib, seaborn, scikit-learn).

## Assessment 1: [Arthritis Prevalence Among Older Adults](assessment-1-arthritis/)
Exploratory analysis of CDC health data, examining how arthritis prevalence
varies by location, sex, race/ethnicity, and year, plus a linear regression
testing whether year alone predicts prevalence.

## Assessment 2: [Predicting Student Final Grades](assessment-2-student-performance/)
Builds and compares three regression models (Linear Regression, Decision
Tree, Random Forest) to predict students' final grades from demographic,
attendance, and prior academic performance data. Linear Regression achieved
the best result (R² = 0.88).
